# Module 1: Core Concepts

## Task 1 - Item list with composition

A React component that renders a list of items, where each item is rendered by its own child component.

- `ItemList` receives the `items` array as a prop and maps over it.
- `ListItem` is responsible for rendering a single item (name, category, description and price).
- Mock data lives in `src/data/items.js`.

## Running locally

```bash
npm install
npm run dev
```
